# WebMerge 🔀

> ブラウザ完結型・ローカルファーストのファイル＆フォルダ差分比較/マージツール

WebMerge は、WinMerge の強力な比較・マージ機能を、インストール不要・外部通信ゼロでどのOS（macOS, Linux, ChromeOS, Windows）でも利用可能にするオープンソースWebアプリケーションです。

---

## ✨ 主な機能

- 🔒 **完全ローカル完結（Zero-Server）**: ファイルやコードは外部サーバーへ一切送信されず、すべてブラウザ内で安全に処理されます。
- 💾 **直接ローカル上書き保存**: File System Access API を活用し、ブラウザ上で編集した内容を元のローカルファイルに直接上書き保存可能。
- 📁 **フォルダ丸ごと比較**: ディレクトリを再帰的に走査し、ファイルの一致・変更・左右の片側存在をリアルタイム判定。
- ⚡ **Web Workerによる非同期スキャン**: 大規模なフォルダでも画面がフリーズせず滑らかに動作。
- 🧠 **Monaco Diff Editor（VS Codeコア）**: シンタックスハイライト、左右分割/インライン切り替え、左右双方向の直接編集をサポート。
- 🎛️ **WinMerge互換オプション**: 空白無視、改行コード（CRLF/LF）統一、除外フィルタ（`.git`, `node_modules` 等）。
- 🌐 **多言語対応（i18n）**: 英語（標準）および日本語に対応。

---

## 🚀 使い方・ローカル開発

### 前提条件
- Node.js (v20以上推奨)
- File System Access API 対応ブラウザ（Google Chrome, Microsoft Edge など）

### セットアップ
```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# 単体テストの実行
npm test

# プロダクションビルド
npm run build
```
